# 🔗 Linkly

Linkly is a smart link management application that helps users save, organize, and access important links in one place. Designed with a clean and user-friendly interface, Linkly makes link management simple and efficient.

## ✨ Features

* Save important links
* Organize links by category
* User authentication
* Profile management
* Quick link access
* Responsive mobile interface

## 🛠️ Built With

* React Native
* TypeScript
* Mysql

## 🚀 Getting Started

```bash
npm install
npm start
```

Run the application on an Android or iOS device using Expo.
